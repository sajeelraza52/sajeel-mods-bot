TUMHARA KAAM (gloria-bite project mein — naya project NAHI banana)
--------------------------------------------------------------------
Firebase Console — gloria-bite project: https://console.firebase.google.com/project/gloria-bite/overview

1. Build → Realtime Database → Create database → Locked mode → Start
   (URL ye banega: https://gloria-bite-default-rtdb.firebaseio.com — config mein pehle se hai)
2. Build → Storage → Get started → Start in production mode
3. Build → Authentication → Users → Add user → Aliyan ka admin email + password banao
   (Gloria Bite ke admin se ALAG email use karo — ye login sirf Aliyan ko do)
4. Realtime Database → Rules → ye paste karo → Publish:
   {"rules":{"products":{".read":true,".write":"auth != null"}}}
5. Storage → Rules → ye paste karo → Publish:
   rules_version = '2';
   service firebase.storage {
     match /b/{bucket}/o {
       match /products/{fileName} {
         allow read: if true;
         allow write: if request.auth != null;
       }
     }
   }
   (Ye rules Admin Panel mein bhi likhe hain — wahan se copy kar sakte ho.)
6. ⚠️ API KEY CHECK (zaroori): Google Cloud Console → APIs & Services → Credentials
   → gloria-bite wali key kholo → agar "HTTP referrers" restriction lagi hui hai
   to us mein balloon site ka domain bhi add karo:
     sajeel-aliyan-balloons.vercel.app/*
   (Sirf gloria-bite.vercel.app/* hoga to balloon site ki Firebase calls block ho jayengi.
   Agar koi restriction nahi lagi to kuch nahi karna.)
7. Deploy: hosting tool se upload karo (saari files — index.html + balloon-1..14.jpg),
   naam: aliyan-balloons  →  link: https://sajeel-aliyan-balloons.vercel.app/
   (Repo sajeel-mods-bot mein v2 pehle se push hai — commit 2a70fec7.)

TEST KARO (deploy ke baad)
--------------------------
1. Site kholo → 14 demo products dikhne chahiye (Firebase lagne se pehle bhi dikhte hain).
2. Footer → Admin Login → Aliyan ka email/password → Login.

4. Naya product add karo: photo chuno, naam/price/description likho, Save → shop par live aaye.
5. Edit dabao → price badlo → Update → shop par badla hua dikhe.
6. Delete dabao → product gayab.
7. Logout karo, dobara login karo — products waise hi hon.

AGAR KUCH NA CHALE
------------------
- "Firebase setup nahi hua" → page purana ho sakta hai — nayi wali index.html deploy karo.
- Photo upload fail → Storage Rules publish nahi hue (step 5) ya Storage on nahi (step 2).
- Login fail → Authentication mein Aliyan ka user nahi bana (step 3) ya Email/Password off hai.
- Products add nahi ho rahe → RTDB Rules publish nahi hue (step 4) ya RTDB bana hi nahi (step 1).
- "API key not valid" ya Firebase bilkul connect nahi ho raha → step 6 (referrer) check karo.
- Rules publish karne ke baad page refresh karo.
