FIREBASE SETUP (Sajeel — tum ne kaha tum banaoge)
--------------------------------------------------
1. Firebase Console kholo: https://console.firebase.google.com/
2. "Add project" → naam: aliyan-balloons → Google Analytics OFF → Create project
3. Build → Authentication → Sign-in method → Email/Password → Enable → Save
4. Authentication → Users → Add user → Aliyan ka admin email + password banao
   (ye login sirf Aliyan ko do — is se wo products manage karega)
5. Build → Realtime Database → Create database → Locked mode → Start
   → databaseURL copy karo (https://aliyan-balloons-default-rtdb.firebaseio.com jaisa)
6. Build → Storage → Get started → Start in production mode
7. Project Settings (gear icon) → Your apps → Web app (</>) → app nickname: aliyan-balloons
   → Register → jo config dikhe (apiKey, authDomain, databaseURL, projectId,
   storageBucket, messagingSenderId, appId) — index.html mein firebaseConfig mein paste karo
   (PASTE_YOUR_API_KEY wali jagah — "TODO (SETUP.txt)" likha hai wahan)
8. Realtime Database → Rules → ye paste karo → Publish:
   {"rules":{"products":{".read":true,".write":"auth != null"}}}
9. Storage → Rules → ye paste karo → Publish:
   rules_version = '2';
   service firebase.storage {
     match /b/{bucket}/o {
       match /products/{fileName} {
         allow read: if true;
         allow write: if request.auth != null;
       }
     }
   }
   (Ye rules Admin Panel mein bhi likhe hain — wahan se copy kar sakte ho.)
10. Deploy: hosting tool se upload karo (saari files — index.html + balloon-1..14.jpg),
    naam: aliyan-balloons  →  link: https://sajeel-aliyan-balloons.vercel.app/

TEST KARO (deploy ke baad)
--------------------------
1. Site kholo → 14 demo products dikhne chahiye (Firebase lagne se pehle bhi dikhte hain).
2. Footer → Admin Login → Aliyan ka email/password → Login.
3. "Demo wale 14 products import karo" dabao → "14 demo products import ho gaye!" aaye.
4. Naya product add karo: photo chuno, naam/price/description likho, Save → shop par live aaye.
5. Edit dabao → price badlo → Update → shop par badla hua dikhe.
6. Delete dabao → product gayab.
7. Logout karo, dobara login karo — products waise hi hon.

AGAR KUCH NA CHALE
------------------
- "Firebase setup nahi hua" → index.html mein firebaseConfig paste nahi hua (step 7).
- Photo upload fail → Storage Rules publish nahi hue (step 9) ya Storage on nahi (step 6).
- Login fail → Authentication mein user nahi bana (step 4) ya Email/Password off hai (step 3).
- Products add nahi ho rahe → RTDB Rules publish nahi hue (step 8).
- Rules publish karne ke baad page refresh karo.
